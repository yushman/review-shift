review-shift

Code review for the branches that never became a PR.

It runs on a schedule you pick, reviews every branch you touched, and leaves a report and a ready-to-apply patch. Your code never leaves the Claude Code session you already trust.

How it works

Three steps, none of them yours

1 · It finds the workBranches whose commits moved since last time, filtered by your own glob patterns. Or every commit that landed straight on main.
2 · It reviews the diffAgainst the merge base, read-only, with secrets masked. Findings come back structured and graded by severity.
3 · It hands you a patchThe diff is built here, not by the model, and must pass git apply --check before it lands on disk. Applying it is your call.

Your rules

Everything on this page is a setting

One .review-shift/config.yml, committed with your repo, so the whole team gets the same behaviour.

When it runsAny hour and minute you like. 18:00 after you log off, 03:30 while you sleep, or never — just call it by hand.
Which branchesGlob or regex patterns, an exclude list, how recent counts as recent, how many per run. Or trunk mode: every commit that landed on main.
How deepTwo levels, per branch cost and time in the table below.
What it may patchA severity floor. Set it to critical and only the serious ones reach the auto-apply patch; everything else stays in the report.
What it never readsPath excludes, on top of four that can't be removed: .env*, secrets/**, *.pem, *.key.
What it may spendA cap per branch and a cap per run. Hit either and the run stops and says so. Defaults: $10 and $50.
Three ways to run it

On a scheduleSet it once, read reports.pipx install review-shift review-shift init review-shift init launchd

Not sure what a night would do? review-shift run --dry-run runs discovery, the diff, redaction and the report with zero model calls, so it costs nothing.

Safety

What it will never do

Touch your working treeNo checkout, no commit, no push, no git apply outside --check. The patch is a file until you apply it.
Get write permissionsRead-only by allowlist. --dangerously-skip-permissions is a config error here, not an option.
Auto-apply something riskyA fix that adds a network call, a subprocess, a dependency or a CI edit never reaches the auto-patch. A human looks at those.
Fail quietlySkipped branches, unpatchable findings and masked regions all reach the report with a reason. "Found nothing" never looks like "reviewed nothing".
FAQ

The questions you're already asking

What do I need before installing?

The Claude Code CLI 2.1.0 or newer, already authenticated, and Python 3.11+. The scheduled path uses launchd, so it's macOS; the CLI itself runs on Linux too, and you can drive it from cron or CI.

Does my code leave my machine?

It goes exactly where a Claude Code session sends it, because that's what runs the review — nowhere else. There's no hosted service, no account, no telemetry. Secrets in the diff are masked first, and four secret-shaped path patterns can never be un-excluded.

What does it cost?

It spends your Claude Code budget, roughly $0.52–$0.77 per branch depending on depth. Nothing is charged by this project. Caps are on by default — $10 per branch, $50 per run — and a run that hits one stops and tells you.

I already have review on pull requests. Why this?

Because this happens before the PR exists. The branch you've been on for three days gets read tonight, while the change is still cheap to alter — and it happens locally, without pushing work-in-progress anywhere.

Will it flood me with nitpicks?

Set the severity floor. Only findings above it reach the auto-apply patch; the rest stay in the report where you can ignore them. The default floor is high.

How good is it, really?

Every patch it generated in the benchmark applied on the first try: 18 of 18, 95% CI 82–100%. On finding defects the corpus is six real upstream bugs — enough to show the deeper level finds about twice as many as the shallower one, not enough for a significance claim, and the project's own harness marks its recall figure as unpublishable. Two of the six were missed by every level.

What if I hate it?

pipx uninstall review-shift. It never wrote to your repository, so there is nothing to undo.
